# Plug-and-Play-Diagnostics-Security-Toolkit
Capstone Project Spring 2026

## Project Overview
Our goal is to create a plug-and-play toolkit that allows users to assess the security of their systems without requiring expert knowledge. Users can select which checks to run, view results on a dashboard, and generate an actionable risk report.

## Modules
- **Service Selection GUI** – Dashboard to choose which assessments to run
- **Network Scanning** – Detects hosts, open ports, and services
- **Configuration & Vulnerability Audit** – Checks system settings and patch levels
- **Process & Service Review** – Analyzes running processes and services
- **Network Traffic Inspection** – Captures and analyzes traffic samples
- **Safe Threat Simulation** – Simulates weak credentials and misconfigurations safely
- **Results Dashboard** – Displays results and alerts
- **Exportable Risk Report** – Summarizes findings with remediation guidance
